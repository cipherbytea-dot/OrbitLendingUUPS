# OrbitLending Protocol 🚀

**OrbitLending** is a decentralized lending protocol built on **Ethereum**, utilizing the **UUPS Upgradeable** pattern for future-proof improvements and **ERC4626** for standardized yield-bearing vaults.

## 🏗 Architecture
- **Core Logic:** UUPS Upgradeable Proxy Pattern.
- **Vault Standard:** ERC4626 (Tokenized Vaults).
- **Security:** OpenZeppelin Contracts v5.0.

## 🛠 Tech Stack
- **Framework:** Foundry
- **Language:** Solidity ^0.8.20

git clone [https://github.com/cipherbytea-dot/OrbitLendingUUPS.git](https://github.com/cipherbytea-dot/OrbitLendingUUPS.git)
